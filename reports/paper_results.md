# Results and Analysis

## 5.1 Visual Tampering Detection

The active visual tampering baseline uses frozen MobileNetV3-Small features (576 dimensions) and Logistic Regression, with authentic=0 and forged=1. On the AIForge-Doc-v1 validation split (n=650), it achieved accuracy 0.607692, precision 0.626812, recall 0.532308, F1 0.575707, and ROC-AUC 0.682670. On the official held-out TestingSet (n=1624), it achieved accuracy 0.520936, precision 0.526074, recall 0.422414, F1 0.468579, and ROC-AUC 0.517846.

These figures evaluate visual tampering classification only. They are not financial fraud-detection or complete-system accuracy.

## 5.2 Model Comparison

The validation comparison considered the existing Logistic Regression, standardized Logistic Regression, linear and RBF SVM, Random Forest, HistGradientBoosting, MLP, and a controlled MobileNetV3-Small partial fine-tune at 96x96. Selection priority was validation F1, then ROC-AUC, then accuracy. The fine-tune had the best validation F1 (0.662400) and ROC-AUC (0.762149). Its official test accuracy was 0.501847 and F1 was 0.470203, below the original LogisticRegression test accuracy 0.520936. This validation/test gap indicates limited generalization; the fine-tune was not promoted, and the original classifier remains active. HistGradientBoosting also had better validation than test results and was not promoted.

## 5.3 Cross-Document Verification

The deterministic verifier explicitly compares extracted fields and returns PASS, FAIL, WARNING, or INSUFFICIENT_DATA. In software integration fixtures, salary net ₹35,000 matched bank credit ₹35,000 (PASS); salary ₹35,000 versus credit ₹25,000 produced FAIL. These are synthetic software-flow examples, not research performance data.

## 5.4 Multimodal Evidence Fusion

Fusion retains OCR, structured fields, cross-document rules, heuristic tampering, trained visual-model output, GNN advisory evidence, and metadata as separate traceable sources. Heuristic tampering observations are not counted as cross-document inconsistencies.

## 5.5 GNN-Based Relational Evidence

The lightweight two-layer PyTorch Geometric GCN with edge classifier was trained on 7 synthetic rule-distillation scenarios and evaluated on 2 validation and 2 held-out synthetic scenarios. Targets are generated by the existing deterministic verifier, not independent ground truth. Held-out agreement was 0.000 on n=2; ROC-AUC is undefined for this split because all classes are not represented. This does not demonstrate independent graph generalization or fraud accuracy. The GNN is advisory and cannot override deterministic rules.

## 5.6 Explainable Risk Assessment

Risk is a heuristic evidence score, not a calibrated probability. Explicit cross-document failures contribute materially. Weak heuristic tampering observations are retained but their aggregate contribution is capped; trained visual probabilities are not treated as calibrated fraud probabilities; GNN output contributes zero direct risk points. Synthetic integration risk examples yielded 16/LOW for the matching fixture and 45/MODERATE for the mismatch fixture; these are software behavior examples only.

## 5.7 Limitations

The active visual baseline is modest (official test ROC-AUC 0.517846). The 96x96 fine-tune did not improve official test accuracy. There is no independent end-to-end financial fraud ground-truth benchmark, no calibrated fraud probability, and no independent graph-labelled corpus. Heuristic tampering can produce false positives. The GNN metrics reflect rule distillation over a tiny synthetic set.

## 5.8 Discussion

The system demonstrates an integrated, evidence-traceable verification workflow rather than a single validated fraud classifier. The official test results show weak visual tampering generalization; higher validation performance did not transfer to improved held-out test performance. Results should therefore be presented as a baseline study and software prototype. No overall fraud-detection accuracy is claimed.
